#  Pomodoro Timer

A simple **Pomodoro Timer** built with **Python and Tkinter** as part of **Angela Yu’s 100 Days of Python** course.

## Features

* 25-minute work sessions
* Short and long breaks
* Automatic session switching
* Visual check marks for completed work sessions
* Tomato-themed GUI using Tkinter


## Requirements

* Python 3.x
* Tkinter (usually included with Python)

## Run the project

```bash
python3 main.py
```

## What I learned

* Tkinter GUI development
* Event-driven programming
* Using `window.after()` for timers
* Managing application state in Python
* Organizing a small Python project for GitHub
